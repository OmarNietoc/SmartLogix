# Evidencia 08 - Defensa oral

## Que evidencia debe ir aqui

- Resumen de exposicion por integrante.
- Preguntas y respuestas tecnicas.
- Guion de demo funcional.
- Capturas o notas de la presentacion final.

## Como generarla

1. Revisar `docs/guia-defensa-oral.md`.
2. Revisar `docs/defensa/preguntas-respuestas.md`.
3. Completar `docs/defensa/resumen-por-integrante.md` con nombres reales.
4. Ensayar el flujo de `docs/demo-guion-funcional.md`.

## Archivo o captura a usar

- `docs/guia-defensa-oral.md`.
- `docs/defensa/preguntas-respuestas.md`.
- `docs/defensa/resumen-por-integrante.md`.
- `docs/demo-guion-funcional.md`.

## Por que sirve para la evaluacion

Prepara respuestas breves, tecnicas y defendibles para justificar arquitectura, pruebas, persistencia, mensajeria, limitaciones y aportes individuales.
